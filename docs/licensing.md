# Licensing & provenance

This repository is MIT-licensed (see the top-level `LICENSE`). That became
possible when the material with unresolved provenance was moved out of the
tracked tree; this document records the boundary honestly.

## What the MIT license covers

The current tree: the shell scripts (`setup.sh`, `setup-linux.sh`,
`clone-repos.sh`, `harden-vps.sh`, `setup-obsidian-sync.sh`, `dot`,
`scripts/`), the `server/` drop-ins, package manifests, and docs. These were
written for this setup. They invoke third-party installers and reuse common
idioms; the install commands and snippets they wrap belong to their upstreams.

## Generated / derived config

- `.p10k.zsh` is generated by Powerlevel10k's `p10k configure` and carries that
  project's upstream notices inline (MIT upstream).
- `.zshrc` derives from the Oh My Zsh template with local edits; Oh My Zsh is
  MIT-licensed upstream.
- `.tmux.conf`, `.gitconfig`, and files under `config/` are small,
  hand-maintained, mostly conventional settings. No broad ownership claim is
  made over individual idiomatic lines.

## Material intentionally NOT in this repo

The opt-in Pi agent scaffold (previously `templates/pi/`) was **adapted from
[dmmulroy/.dotfiles](https://github.com/dmmulroy/.dotfiles)**, which publishes
no license — meaning all rights reserved by default. Rather than distribute it
under a license we cannot grant, it was moved to a private companion repository
and is installed locally via `DOTFILES_PI_SCAFFOLD_DIR` (see
`config/dotfiles/local.env.example`). If that upstream ever gains a license or
grants permission, the scaffold could return.

**Git history caveat:** the scaffold existed in this repository before its
removal, so it remains reachable in git history. The MIT license applies to the
current tree only; do not treat historical revisions of `templates/pi/` as
licensed material.

## Installed-but-not-vendored software

Setup scripts install third-party tools (Homebrew formulae/casks, npm packages,
Oh My Zsh, Powerlevel10k, Herdr, Hunk, Tailscale, etc.). Those retain their own
upstream licenses; this repo only automates fetching them and vendors no
lockfiles for them.
